# The question

*One paragraph, rewritten each November and dated. Never overwritten: each year is added below the one before it, so the version history and this file both hold the trajectory.*

**What it answers:** what the practice has found this year. Not what was made, and not what the work is about.

**Why it exists:** every grant form, residency application and doctoral file asks a version of this. It is the only item in the whole system that costs nothing, and ten dated versions of it are evidence of sustained independent research that no coursework could produce.

**How to write it:** one paragraph, under two hundred words, in the register of the Writing page rather than in grant language. Write it after the catalogue is closed, so it is written against a year of actual work rather than against an intention.
