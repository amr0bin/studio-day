## What this covers

You have already agreed to sit. This is about what happens to the image of the finished work afterwards, and it is separate because some of these things cannot be undone.

## The thing that cannot be undone

Some places I may put the work are permanent by design. A research repository issues the record a permanent identifier and keeps it as long as the organisation exists. Once a file is published there, it can be restricted from view but the record stays. Please read that sentence twice before ticking the deposit box.
